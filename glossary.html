Glossary

A quick reference for the language of AI and open source.

Words you’ll meet

In one line

Look up a term, then return to the Part where you met it.

Access token
A password-like key that lets a program use an account (e.g. a GitHub token)
Agent
An AI system that does multi-step tasks using tools, in a loop
Agent skill
A folder with a SKILL.md that teaches an agent one repeatable task
API
A fixed way for one program to ask another to do something
API key
A secret code that lets your program use an API
Apache-2.0
A permissive license like MIT, with patent wording
Architecture
The design of a model: how its layers are arranged
Backend
The server-side part of an app that users don't see
Branch
A separate line of work in a Git repo; main is the default
CI
Automatic checks (like tests) that run when you push code
Closed model
A model you can only use through an app or API; no downloadable weights
Commit
A saved snapshot of changes in Git, with a message
Context window
The most text (in tokens) a model can handle at once, including its reply
Contributor
Anyone who helps an open-source project
Copyleft
Anyone who passes the software on must keep it under the same open terms (e.g. GPL)
Copyright
The creator's legal right over their work
Dataset
A collection of data, for example for training a model
Dependency
A package your project needs
Diff
A view of exactly what changed in a file
Endpoint
One specific URL that an API answers on
Environment variable
A named value a program reads from its surroundings, not from its code
.env / .env.example
A local file of real keys (never commit) / a copy with fake values (safe to commit)
Few-shot prompting
Giving the model one or two examples of the output you want
Fork
Your own copy of someone else's repo
Frontend
The part of an app the user sees
Gated model
A model you must log in and accept the license for before downloading
Git / GitHub
A tool that tracks code changes / a website that hosts Git repos
.gitignore
A file listing what Git must never track
GPL-3.0
A copyleft license; distributing the program means sharing its source under GPL
GPU
A chip that does many calculations at once; makes models faster
GUI
A graphical interface with windows and buttons
Hallucination
Confident model output that isn't true
Harness
The software around a model: instructions, tools, memory, actions
HTTP
The system browsers and APIs use to send requests and responses
Hugging Face
A website for sharing models, datasets, and demos
IDE
A code editor with extra tools
Inference
Running a trained model on new input
Issue
A public note about a bug, idea, or question in a repo
JSON
A text format for structured data, like {"room": "B-204"}
Least privilege
Giving a tool or token only the access it needs
License
Legal permission and conditions for using and sharing a work
LLM
Large Language Model, a model trained on huge amounts of text
localhost
"This same computer"
Maintainer
A person who runs a project and accepts changes
MCP
Model Context Protocol, a standard way for AI apps to connect to outside tools
Merge
Accepting a change into the main code
MIT
A simple, permissive license: do almost anything, keep the notice
Model
A trained program that uses learned numbers to turn input into output
Model card
The official page for a model: purpose, size, limits, license
Model family
A group of related models from one maker (e.g. Gemma)
Model ID
The exact name of one specific model version
MVP
Minimum viable product, the smallest version that really works
Ollama
A local runner for open-weight models (not a model)
Open-source AI
The necessary model parts, code, and data information available under open terms to use, study, modify, share
Open-source software
Public code with an open-source license
Open-weight model
A model whose weights you can download and run under its license
OSI
Open Source Initiative, which maintains the definition of open source
Parameters
Another word for weights
Prompt
Everything you send the model in one turn
Prompt engineering
Writing prompts on purpose so the model makes fewer mistakes
Prompt injection
Hidden instructions in outside text that try to control a model
Pull request (PR)
A request to merge your changes into a project
Quantization
Storing weights with fewer bits: smaller and faster, slightly less accurate
Repository (repo)
A project folder tracked by Git
Rotate a key
Cancel a leaked key and replace it with a new one
Runner
Software that loads a model and serves it (e.g. Ollama, llama.cpp)
Secret
Any key, token, or password that unlocks an account
Server
A computer that is always on and answers requests
Stack
The set of tools you build with
Status code
A number in an API response saying what happened (e.g. 200, 404)
System prompt
Standing instructions an app gives the model
Terminal
A text window where you type commands
Token
A chunk of text a model reads or writes, about ¾ of an English word
Tokenizer
The part that splits text into tokens for the model
Training
Adjusting a model's weights by learning from many examples
Validation
Checking that data is correct before using it
Weights
The numbers a model learned during training

No terms match. Try a shorter word.
