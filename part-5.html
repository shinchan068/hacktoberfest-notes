Understand what skills and MCP add to an agent.

16 Agent skills (SKILL.md)

In one line

A skill is a folder with a SKILL.md that tells an agent exactly how to do one repeatable task.

  • A skill is a reusable folder with a SKILL.md playbook, optionally with scripts and templates.
  • Its description tells the agent when to load it. Good skills have a specific trigger, concrete steps and a checkable result.
  • Skills guide behavior; they are not models and do not grant permissions or connect accounts.
Full notes & examples

An agent skill is a reusable playbook for an agent: a folder of instructions the agent loads when your task matches it.

  • The instructions go in a file named SKILL.md. Markdown (.md) is a simple text format where # makes a heading and - makes a bullet point.
  • Optional extras: scripts, templates, a LICENSE.
  • The skill is loaded only when the task matches its description.
  • A skill is not a model, and it does not give the agent extra permissions. It only guides what the agent does.
  • The public specification is at agentskills.io. Real examples are at github.com/anthropics/skills, where each folder (pdf, docx, and so on) is one skill.

Example: a ship-checklist skill

ship-checklist/
  SKILL.md
  templates/README-template.md
  scripts/check-repo.sh

Inside SKILL.md:

---
name: ship-checklist
description: Check a project repo before sharing it.
---
# Steps
1. Check README and LICENSE.
2. Confirm exact model ID and license link.
3. Look for committed secrets.
4. Run tests and summarize failures.
5. Report what is left to do.

The part between the --- lines holds the name and description. The agent uses the description to decide when to load the skill.

  • Good skill: a specific trigger (when to use it), concrete steps, and a result you can check.
  • Bad skill: a long essay nobody follows.

Other ideas: a skill for wiring up a model safely, generating a README, or rehearsing a project demo.

Check yourself

  1. What file must every skill have?

    Reveal answer
    SKILL.md.

  2. Does adding a skill give an agent access to GitHub?

    Reveal answer
    No.

  3. What makes a skill good?

    Reveal answer
    A specific trigger, concrete steps, and a result you can check.

17 MCP (Model Context Protocol)

In one line

MCP is a standard plug that lets an AI app use outside tools like GitHub or Sheets, with your permission.

  • MCP is a standard for connecting AI apps to external tools and data. The host contains a client that talks to an MCP server.
  • A skill tells an agent which steps to follow; an MCP server offers tools such as reading files or listing issues.
  • Start with one understood connector. Use least privilege, protect tokens and review actions that change or delete things. MCP is not a model.
Full notes & examples

MCP is a standard way for AI apps to connect to outside tools and data, such as Google Docs or Sheets, GitHub, Slack, databases, browsers, or your own APIs. A protocol is an agreed set of rules for how programs talk.

Analogy: MCP is like USB for AI tools: one plug shape works with many devices.

The pieces

  • Host: the AI app you use, such as Cursor, Claude, or your own agent.
  • MCP client: the part inside the host that talks to servers.
  • MCP server: a small program that offers tools to the host, for example "list issues" or "read file".
  • You: connect it once, approve actions, and watch what it does.

Without vs with MCP

  • Without MCP: you copy-paste issues and code into the chat.
  • With a GitHub MCP server: the agent can list issues, read files, and open PRs with your permission.

Common patterns

  • Docs in context: a Docs or Drive MCP lets the agent read your project brief.
  • Sheets as a mini database: log results to a Google Sheet.
  • Repo work: a GitHub MCP for issues, PRs, reading files, and checking CI. (CI, Continuous Integration, means automatic checks such as tests that run every time you push.)
  • Custom: your own MCP server around an API you control, properly secured.

Start simple: one connector you understand beats five half-broken ones.

Skills vs MCP vs model

Answers the questionExample
ModelWhat produces the output?Gemma
HarnessWhat runs the model and its tools?A coding agent
SkillWhich steps should be followed?A submission checklist
MCPHow does it connect to outside tools?A GitHub MCP server

Safety

  • Give access tokens (password-like keys for programs) only the access they need. This is called least privilege.
  • Never paste tokens into a chat or a README.
  • Connecting a tool doesn't make every action safe. Review anything that deletes or changes things.
  • MCP is not a model and doesn't make anything open-weight.
Check yourself

  1. What is the difference between an MCP host and an MCP server?

    Reveal answer
    The host is the AI app. The server offers tools to it.

  2. How is a skill different from an MCP server?

    Reveal answer
    A skill gives steps to follow. An MCP server provides a connection to an outside tool.

  3. What does "least privilege" mean?

    Reveal answer
    Giving only the access that is really needed.
